# У Агента Гермес «Рутины» есть еще с марта

Anthropic только что анонсировала [Claude Code Routines](https://claude.com/blog/introducing-routines-in-claude-code) — запланированные задачи, триггеры событий GitHub и запуски агентов через API.

Это отличная функция. Мы выпустили её два месяца назад.

---

## Три типа триггеров — сравнение

Claude Code Routines предлагает три способа запуска автоматизации:

**1. По расписанию (cron)**
> "Каждую ночь в 2 часа ночи: взять верхнюю ошибку из Linear, попытаться исправить и открыть черновик PR."

Эквивалент в Гермесе — работает уже сегодня:
```bash
hermes cron create "0 2 * * *" \
  "Возьми верхнюю ошибку из трекера, попробуй исправить и открой черновик PR." \
  --name "Ночное исправление ошибок" \
  --deliver telegram
```

**2. События GitHub (webhook)**
> "Помечать PR, которые затрагивают модуль /auth-provider, и отправлять в #auth-changes."

Эквивалент в Гермесе — работает уже сегодня:
```bash
hermes webhook subscribe auth-watch \
  --events "pull_request" \
  --prompt "PR #{pull_request.number}: {pull_request.title}. Проверь, затрагивает ли он модуль auth-provider. Если да, опиши изменения." \
  --deliver slack
```

**3. Триггеры API**
> "Прочитать данные алерта, найти ответственный сервис, отправить сводку в #oncall."

Эквивалент в Гермесе — работает уже сегодня:
```bash
hermes webhook subscribe alert-triage \
  --prompt "Алерт: {alert.name} — Важность: {alert.severity}. Найди ответственный сервис, разберись и предложи первые шаги." \
  --deliver slack
```

Каждый сценарий из их блога — сортировка бэклога, проверка документации, верификация деплоя, корреляция алертов — уже имеет рабочую реализацию в Гермесе. Новые функции не требуются. Это работает с марта 2026 года.

## Что Гермес умеет, а Routines — нет

### Инъекция скриптов

Запустите скрипт на Python *перед* агентом. Вывод скрипта становится контекстом. Скрипт берет на себя механическую работу (сбор данных, сравнение); агент берет на себя рассуждения.

```bash
hermes cron create "every 1h" \
  "Если ОБНАРУЖЕНЫ ИЗМЕНЕНИЯ, опиши их. Если ИЗМЕНЕНИЙ НЕТ, ответь [SILENT]." \
  --script ~/.hermes/scripts/watch-site.py \
  --name "Мониторинг цен" \
  --deliver telegram
```

Паттерн `[SILENT]` означает, что вы получите уведомление только тогда, когда что-то действительно произойдет. Никакого спама.

### Гибкая доставка

Одна автоматизация, любое назначение:

```bash
--deliver telegram                      # Домашний канал Telegram
--deliver discord                       # Канал Discord
--deliver slack                         # Канал Slack
--deliver sms:+15551234567              # SMS-сообщение
--deliver local                         # Сохранить в файл, без уведомления
```

## Лимиты говорят сами за себя

Claude Code Routines: **5 рутин в день** на тарифе Pro. **25 на Enterprise.** Это их потолок.

У Гермеса нет дневного лимита. Запускайте хоть 500 автоматизаций в день. Единственное ограничение — ваш бюджет на API, и вы сами выбираете, какие модели использовать для каких задач.

## С чего начать

Агент Гермес — это проект с открытым исходным кодом. Вся инфраструктура автоматизации — планировщик cron, платформа вебхуков, система навыков и мультиканальная доставка — уже встроена.

```bash
pip install hermes-agent
hermes setup
```

Настройте задачу по расписанию за 30 секунд:
```bash
hermes cron create "0 9 * * 1" \
  "Сгенерируй еженедельный дайджест новостей ИИ. Найди главные анонсы и трендовые репозитории. Не более 500 слов, со ссылками." \
  --name "Еженедельный дайджест" \
  --deliver telegram
```
